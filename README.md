# بوت واتساب هسة

بوت يرد على المتاجر والمندوبين والزبائن، يرسل إشعارات الطلبات ورموز OTP،
ويوفّر إنبوكس ويب لفريقك — كله من رقم واحد: **+964 788 000 7715**

---

## شنو يسوي

| المسار | شنو يصير |
|---|---|
| 🏪 **متجر** | 4 أسئلة (الاسم، النوع، المنطقة، **موعد التصوير**) → يحفظ الليد → تنبيه لفريقك |
| 🛵 **مندوب** | 3 أسئلة (الاسم، الدراجة، المنطقة) → يحفظ الليد → تنبيه لفريقك |
| 🛒 **زبون** | تتبع طلب / أسئلة شائعة / تحويل لموظف |
| 📱 **روابط التطبيقات** | أي واحد يكتب "تطبيق" أو "رابط" أو "حمل" يوصله الثلاثة |
| 🔔 **إشعارات** | سيرفر هسة ينادي `/send-template` |
| 🔐 **OTP** | سيرفر هسة ينادي `/send-otp` |
| 📥 **إنبوكس** | صفحة ويب لفريقك يشوفون ويردون على كل المحادثات |

الزبون يگدر يكتب **0** بأي وقت ويرجع للقائمة الرئيسية.

---

## الإنبوكس

```
https://<الدومين>/inbox?key=<INBOX_KEY>
```

يفتح بأي متصفح — موبايل أو لابتوب. يعرض:

- كل المحادثات مرتبة بالأحدث، مع عدّاد غير مقروء
- وين واصل كل زبون بالمحادثة (تسجيل متجر / مندوب / ينتظر موظف)
- الرد المباشر — يوصل من رقم هسة
- تحذير نافذة الـ 24 ساعة (بعدها الرد يحتاج تمبلت)
- زر إيقاف البوت لكل محادثة — لما الموظف يمسكها البوت يسكت،
  ويرجع يشتغل إذا الزبون كتب `0`

الصفحة تحدّث نفسها كل 5 ثواني.

> المحادثات محفوظة بالذاكرة + ملف `inbox.jsonl`. إذا السيرفر انعاد تشغيله
> يضيع السجل المعروض. لو تريد سجل دائم، وصّل `LEADS_WEBHOOK_URL` بقاعدة
> بيانات أو Google Sheet.

## التشغيل

```bash
npm install
cp .env.example .env   # عبّي القيم
npm start
```

### متغيرات البيئة

| المتغير | شنو يسوي |
|---|---|
| `D360_API_KEY` | مفتاح 360dialog — من داشبورد القناة ← Details ← API Settings |
| `INTERNAL_TOKEN` | توكن سري ينادي بيه سيرفر هسة `/send-otp` و `/send-template` |
| `INBOX_KEY` | مفتاح صفحة الإنبوكس |
| `OTP_TEMPLATE` | اسم تمبلت الـ OTP (افتراضي `hassah_otp`) |
| `TEAM_NOTIFY_NUMBERS` | أرقام فريقك، مفصولة بفاصلة — يوصلهم تنبيه بكل ليد |
| `LEADS_WEBHOOK_URL` | رابط يوصله JSON بكل ليد جديد (اختياري) |

### الويبهوك

بـ `app.360dialog.com` ← Details ← **Channel Webhook URL**:

```
https://<الدومين>/webhook
```

## الـ API

كل الطلبات تحتاج `Authorization: Bearer <INTERNAL_TOKEN>`،
والأرقام بصيغة `9647XXXXXXXXX` — بدون `+` وبدون `00` وبدون صفر البداية.

### إشعار بتمبلت

```bash
curl -X POST https://<الدومين>/send-template \
  -H "Authorization: Bearer $INTERNAL_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"phone":"9647801234567","template":"hassah_order_confirmed","params":["1042","5,000"]}'
```

### رمز تحقق

```bash
curl -X POST https://<الدومين>/send-otp \
  -H "Authorization: Bearer $INTERNAL_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"phone":"9647801234567","code":"483920"}'
```

> ⚠️ خلّي SMS شغّال كـ **fallback**: إذا رجّع خطأ أو تأخر أكثر من 5 ثواني،
> أرسل الرمز بـ SMS. ما ينفع مستخدم واحد ينحبس برا التسجيل.

## تعديل الكلام

كل النصوص والأسعار والروابط بملف **`flows.js`**:

```js
const PRICING = {
  deliveryFee: '5,000',   // أجرة التوصيل الي يدفعها الزبون
  courierMin:  '2,000',   // أقل حصة للمندوب
  courierMax:  '3,000',   // أعلى حصة للمندوب
};
```

عدّل وأعد التشغيل — ما تحتاج تلمس الكود.

**حدود واتساب** (تجاوزها = الرسالة تنرفض):

| العنصر | الحد |
|---|---|
| نص الزر | 20 حرف |
| عدد الأزرار | 3 |
| عنوان صف بالقائمة | 24 حرف |
| وصف صف | 72 حرف |
| عدد صفوف القائمة | 10 |
| نص الرسالة | 1024 حرف |

بعد أي تعديل:

```bash
node test-flow.js
```

يمثّل محادثات كاملة بدون ما يلمس واتساب، ويتحقق من كل الحدود.

## نقاط مهمة

**نافذة الـ 24 ساعة.** أي رسالة يبديها الزبون تفتح نافذة 24 ساعة ترد بيها
مجاناً وبدون تمبلت. ردود البوت وردود الموظف من الإنبوكس كلها داخل هالنافذة
— **مجانية**. الي ينحسب عليك هو بس الي تبديه انت (OTP والإشعارات).

**سقف الرسائل.** واتساب يحسب **مستخدمين فريدين لكل 24 ساعة**، مو عدد
الرسائل. الحساب حالياً على **250**. لا تحوّل كل قاعدة المستخدمين دفعة
وحدة — أرسل الإشعارات مع الأحداث الحقيقية، وميتا ترفعك تلقائياً.

**التحويل لموظف.** لما الزبون يختار "أحچي مع موظف"، أو لما الموظف يرد من
الإنبوكس، البوت يسكت لهالمحادثة. يرجع يشتغل إذا الزبون كتب `0`.
